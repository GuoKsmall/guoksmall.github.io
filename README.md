# 果_k / Guok

个人主页：<https://guok.ink/>

使用静态 HTML、CSS 和 JavaScript，沿用原有头像、表情图、游戏截图、漫展照片及联系方式。视觉参考 [Arc UI](https://uiarc.dev/) 的中性色、紫桃渐变、圆角卡片和轻量交互，以原生 CSS 实现，无构建依赖。

包含独立的北京时间昼夜天空与时光预览、深浅色切换、相册分类及支持方向键 / Esc 的大图预览。动画遵循系统的减少动态效果设置。

本地预览：`python3 -m http.server 8000`。基础检查：`node check.mjs`。

GitHub Pages 发布源：`main` 分支的根目录。推送到 `main` 后自动更新，`CNAME` 保持 `guok.ink`。

素材来源与版权说明见 [assets/CREDITS.md](assets/CREDITS.md)。
